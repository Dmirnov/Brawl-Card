# Продолжение работы — 9 ноября 2026

Основной плейс Roblox Studio: «Карта сражений».

## Что сохранено
- `Brawl Card/src/server/WorldSetup.server.lua` — текущая версия центральной карты и личных баз. При запуске скрипт очищает Terrain и большие детали Baseplate, которые создают плоский зелёный мир.
- `BrawlCard_Полный_пакет.md` — полный пакет скриптов и подсказки, куда их помещать.
- Исходные материалы проекта из GitHub сохранены в папке `Brawl Card`.

## Чтобы продолжить
1. Открой плейс в Roblox Studio.
2. Проверь `ServerScriptService > WorldSetup`: это обычный Script с кодом из `Brawl Card/src/server/WorldSetup.server.lua`.
3. Сохрани плейс, останови старый Play/Team Test и запусти заново — очистка старой плоской карты применяется при новом старте.
4. Если редактируете вместе с другом, сначала завершите общий Team Test и затем запускайте новый.

Загрузка файлов в GitHub не обновляет плейс Roblox Studio автоматически. После изменений в Studio сохраняй плейс отдельно.
