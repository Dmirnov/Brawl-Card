# Brawl Stars RNG Tycoon — Roblox (Luau)

Первый этап мира: стартовая точка игрока и трейд-зона.

## Запуск в Roblox Studio

1. Установите Rojo и плагин Rojo для Roblox Studio.
2. В терминале этой папки запустите `rojo serve`.
3. Подключите плагин Rojo в Studio к локальному серверу.
4. Скрипт создаст в Workspace два объекта: `PlayerSpawn` и `TradeZone`.

`TradeZone` пока является визуальной зоной с ProximityPrompt. Торговая логика и интерфейс будут следующим этапом.
